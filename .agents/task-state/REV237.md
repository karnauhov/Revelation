# REV237 - Snap Store на следующем входе в Ubuntu

[Общий чеклист REV237](https://ai11.link/cabinet/tasks?project=1&task=REV237)

Кандидат `1.0.8+178`, исходник `bf335de19246f63959040bb6395c30529cf4370c`. Установка и запуск готового Snap до публикации проверены Linux-координатором. Запрос на следующий вход фиксирует [snap-publication.json](../../scripts/local_release/snap-publication.json). Прежний `latest/stable` - `1.0.7.172`, ревизия 6, amd64. Разрешение владельца относится к этому готовому пакету.

При входе общий диспетчер подтягивает `main` обоих репозиториев и обрабатывает запрос после синхронизации меток удаления. Он загружает только `Revelation-linux-1.0.8-178-amd64.snap` с [проверенного зеркала релиза](https://github.com/karnauhov/Revelation/releases/tag/v1.0.8%2B178), сверяет размер, SHA-256, SHA3-384, тег и исходный SHA. Авторизация берётся из имеющейся сессии Snapcraft в Ubuntu. После загрузки проверяется SHA3-384 опубликованной ревизии. В Windows возвращается квитанция `phase=snap-store-publication` через существующий канал Linux-отчётов.

Если автозапуск сообщил об отсутствующем доступе, в Ubuntu выполни штатный `snapcraft login` под действующим издателем Revelation. Запусти `bash scripts/local_release/run-linux.sh` из Revelation. Если Snap Store уже получил нужную версию, проверь результат модерации и хеш ревизии перед продвижением в `latest/stable`. Используй `snapcraft status revelation-x` и `snapcraft revisions revelation-x`, либо `list-revisions` в старой версии. При необходимости используй ту же принятую копию из каталога. Сборка и повышение номера для публикации исключены.

После выхода 178 в `latest/stable` открой публичную карточку и проверь установку/обновление на доступной изолированной Linux-среде. Сними в реальном Linux-приложении параллельное чтение OH1988 и LXX/TR, отдельно сведения о модуле и сноску 1:1.
