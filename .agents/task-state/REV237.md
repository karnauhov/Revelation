## Следующий вход в Linux

Владелец поручил выполнить оставшееся при следующем входе, без отдельной перезагрузки ради каждого этапа. Продолжить REV237 в графической Ubuntu-сессии и до её окончания выполнить весь этот план. Фоновый диспетчер уже выполнил публикацию; он не выполняет произвольную съёмку UI. Нужен активный агент со штатным UI-инструментом. Сначала прочитать живую REV237 и [навык публикации](../skills/revelation-publish/SKILL.md), сохранить единый чеклист задачи.

1. Проверить `snapcraft status revelation-x`, `snapcraft revisions revelation-x` и публичный канал. Подтвердить ревизию 7 по хешу. При неожиданном более новом канале остановить только установку старого кандидата и согласовать фактический выпуск; не понижать новую версию автоматически.
2. Обновить локальную установленную версию из магазина: `sudo snap refresh revelation-x --channel=latest/stable`; если Snap отсутствует, `sudo snap install revelation-x --channel=latest/stable`. Сохранить пользовательские данные. `snap list revelation-x` должен показывать `1.0.8.178`, ревизию 7 и `latest/stable`. `sudo sha256sum /var/lib/snapd/snaps/revelation-x_7.snap` должен совпасть с указанным SHA-256. Оставить новую версию установленной.
3. Открыть именно Store Snap. Проверить загрузку OH1988: schema 4, data 2, дата 31.10.2026; полный Откр. 1:3; параллельное чтение OH1988 и LXX/TR; сноску Откр. 1:1. Strong доступен у LXX/TR и отсутствует у OH1988. Для изолированной проверки использовать собственные данные/настройки, сохранив состояние владельца.
4. Снять минимум три настоящих Linux-кадра: параллельное чтение Откр. 1:1-3, сведения о модуле OH1988 с data 2, открытая сноска 1:1. Язык интерфейса согласовать с карточкой (английский предпочтителен), украинский текст модуля сохранить. Просмотреть каждый фактический кадр. Не выдавать Web/Windows за Linux и не создавать постановочные изображения.
5. Обновить [листинг](https://snapcraft.io/revelation-x/listing): сохранить актуальные кадры первоисточников, заменить прежний широкий снимок чтения и временный общий Windows-кадр новыми Linux-кадрами. Старый About 1.0.3 уже удалён. Максимум пять изображений: два актуальных первоисточника + три новых сценария. Описание и блок New in 1.0.8 уже опубликованы, повторять их без причины не нужно. Проверить порядок, сохранение и [публичную карточку](https://snapcraft.io/revelation-x).
6. Сохранить исходники/проверки в Windows `.local-releases/REV237/`, если диск доступен, либо в одном ограниченном Linux outbox до проверенной передачи. Не загружать изображения в GitHub/AI11. Обновить один отчёт `.local-releases/REV237/report.ru.md` и пункты AI11 по факту. Закрыть свои тестовые окна, освободить управление. До окончания этих действий не предлагать возврат в Windows.
