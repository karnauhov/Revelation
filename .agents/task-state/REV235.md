- D14, 15-28 ноября включительно. Разовый замер 01.12.2026 в 12:00 Europe/Madrid, `rev235-d14`.

В каждом замере получить Acquisitions, внутренний трафик Microsoft Store, Campaign Conversion по CID, Usage и Search Console по диапазонам отчёта. Зафиксировать покрытие и сравнить абсолютные числа с D0 и G01. По D7 снова открыть паузу до D14. По полному D14 записать решение и передать REV235 на ревью.
