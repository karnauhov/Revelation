# REV211 - навигация по номерам Стронга

В словаре переход между статьями остаётся на текущей странице и сохраняет номер и прокрутку для следующего входа из меню. На листе первоисточника выбор номера открывает статью в панели описания. Панель и выделение на листе используют один выбранный номер. В других разделах греческая ссылка открывает диалог, его нижняя кнопка ведёт на полную страницу. В заголовке диалога показаны номер, слово и значок информации, ниже - название словаря.

Проверки для продолжения разработки находятся в `integration_test/primary_source_image_tools_test.dart` и `integration_test/smoke/bible_reference_sources_smoke_test.dart`. Статус и результаты сохранены в [REV211](https://ai11.link/cabinet/tasks?project=1&task=REV211).
