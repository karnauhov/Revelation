# Как проверить библейский текст и результат поиска аллюзий

Запускай команды из корня Revelation. Для чтения стихов нужен Python 3. Для поиска аллюзий нужны также Flutter из PATH и установленные зависимости проекта. Команда выполняется в консоли без открытия приложения.

## Стих по обычной ссылке

```powershell
python -X utf8 .agents/skills/revelation-study/scripts/query_passage.py verse "Откровение 22:6"
python -X utf8 .agents/skills/revelation-study/scripts/query_passage.py verse "Rev 1:1" --module kjv
```

Команда берёт названия книг и ключи стихов из штатного [BibleCatalog](../../../../scripts/content_tool/bible_map.py). Она открывает выбранную БД из `web/db` для чтения и печатает адрес, ключ, имя модуля, версию и исходный текст со всей сохранённой разметкой. Поддерживаются `lxx_tr` (по умолчанию), `kjv` и `ohienko_1988`. Для проверки контекста прочитай также соседние стихи. Сопоставляя рукописи, обратись к листам и аппарату из [каталога источников](../../../../docs/ru/content/revelation-study-sources.md).

## Поиск REV113

```powershell
python -X utf8 .agents/skills/revelation-study/scripts/query_passage.py allusions "Rev 1:1" --length 1 --limit 1
python -X utf8 .agents/skills/revelation-study/scripts/query_passage.py allusions "Rev 1:1" --length 3 --limit 1
```

Укажи начальный стих и длину от 1 до 77 стихов. Параметр `--scope` принимает `oldTestament` (по умолчанию), `newTestament` и `wholeBible`. Параметр `--level` принимает `verse` (по умолчанию), `chapter` и `book`. Число после `--limit` ограничивает вывод. Для проверки отсутствия кандидата выведи все результаты, задав предел не меньше значения `total`.

Команда запускает `flutter test --no-pub`, загружает карту стихов и двоичный индекс приложения, сверяет его метаданные с комплектной греческой БД и вызывает штатный `AllusionIndex.search`. Так же загружает индекс [проверка совпадения с корпусом](../../../../test/features/allusion_search/allusion_corpus_parity_test.dart). Результат содержит фактические границы отрывка, область, уровень, число совпадений, контрольную сумму корпуса, места в выдаче, оценки и общие номера Strong. Для глав и книг адрес указывает первый стих в группе по ранжированию приложения.

В [пилотном досье](../../../../docs/ru/content/study/rev-01-01-03/evidence.md#два-опыта-с-поиском-rev113) контрольный результат первого запроса - Быт. 24:7, 1 из 44, оценка 0,308618. Результат второго - Ис. 50:4, 1 из 208, оценка 0,243665. При иной версии корпуса сохрани новые фактические значения. Для каждого кандидата прочитай оба отрывка в контексте и объясни, насколько сходство слов, порядка мотивов и содержания поддерживает предполагаемую связь.
